Getting GTAP data from the GTAP database

The GTAP data is licensed for use, and can be acquired from INSERT LINK HERE.

Note the following conditions:

  1. You will need the data provided as a FlexAgg package;

  2. The data must have the following files in the 'Fujitsu' Header Array FORTRAN format (extension .har): "gsdfset.har" (GTAP sets), "gsdfpar.har" (GTAP parameters), and "gsdfdat.har" (GTAP data).

Aggregating GTAP data

The functions Helpers.cluster_regions, Helpers.cluster_commodities, and Helpers.cluster_endowments can help with preparing NamedArrays to be passed to GlobalTradeAnalysisProjectv7.aggregate_data() to aggregate the GTAP data based on modelling needs.

Warnings

A non-exhaustive list of issues discovered while using GlobalTradeAnalysisProjectv7.jl are laid out below, to serve as reference points for users of EpiEconShocks.jl encountering the same issues.

  1. Using the full GTAP dataset (even at the FlexAgg stage WHAT IS A GOOD DESCRIPTOR FOR THIS DATA??) to set up an initial model is prohibitively memory intensive. For example, it fails on a 32 GB RAM machine during local testing. Users are strongly advised to aggregate the data to the geographies of concern using the function GlobalTradeAnalysisProjectv7.aggregate_data. We suggest that an appropriate aggregation would be to the countries of interest, and their major trading partners; all other regions can be aggregated into a 'rest of world' category.
